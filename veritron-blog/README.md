# Veritron — personal blog

A fast, secure, privacy-first personal blog on [Eleventy](https://www.11ty.dev/). Bengali-first (English UI included), static output, **no runtime server, database or third-party JavaScript**.

```bash
npm install
npm start              # dev server (drafts + future posts visible)
npm run new -- "পোস্টের শিরোনাম" --category=science
npm run verify         # secrets scan + tests + production build + quality gate
npm run build          # production build → _site/ and regenerates firebase.json
firebase deploy --only hosting
```
Requires Node ≥ 20 (`.nvmrc` = 22).

## Configure
Everything lives in **`site.config.json`**: title, tagline, author bio/avatar, social links, feature switches, analytics, comments, security. `lang: "en"` switches the entire UI to English (strings in `src/_data/t.js`). `SITE_URL=… npm run build` overrides the domain for previews.

## Writing
Posts are Markdown in `src/articles/` (URL stays `/articles/<slug>/`). Front matter:

| key | purpose |
|---|---|
| `title`, `date`, `category`, `tags`, `excerpt` | required basics (excerpt feeds cards, search, feeds, social) |
| `subtitle`, `image`, `imageAlt`, `imageCaption` | header + hero |
| `featured: true` | eligible for the home-page lead slot |
| `updated` | shows "Updated" and sets `dateModified` |
| `draft: true` | visible in dev only; **excluded from production** |
| future `date` | scheduled — hidden in production until that day (rebuild daily) |
| `series`, `seriesOrder` | adds a series navigator |
| `aliases: [old URLs]` | permanent redirects (written into `firebase.json`) |
| `canonical`, `slug`, `comments: false` | overrides |

Three or more `##`/`###` headings produce a sticky table of contents. Footnotes, tables and fenced code (build-time syntax highlighting) are supported.

## Features
**Reading:** light/dark/auto theme without flash · text-size control · reading progress · sticky TOC with scroll-spy · heading deep-links · code copy buttons · image lightbox · related posts (tags › category › series) · newer/older · series navigator · print stylesheet · "read later" list (stored only in the browser).
**Discovery:** instant full-text search (⌘/Ctrl+K or `/`; Bengali-aware, Bengali↔ASCII digits, tag results, keyboard navigable) · categories, tags, year/month archive, paginated listings · random post · Atom + JSON feeds (site and per category) · sitemap · JSON-LD (BlogPosting, BreadcrumbList, WebSite) · Open Graph/Twitter cards.
**Platform:** installable PWA with offline reading (service worker, offline page) · view transitions · self-hosted fonts · hashed, minified, code-split assets (~16 kB gzip CSS+JS) · optional giscus comments · optional analytics (off by default; GA4 only after consent, Plausible/Umami cookieless).
**Share:** WhatsApp, Facebook, X, Telegram, e-mail, native share sheet, copy link.

## Security model
- Strict **CSP** (`default-src 'none'`, no `unsafe-inline`/`eval`), HSTS, nosniff, `frame-ancestors 'none'`, Referrer/Permissions-Policy, COOP/CORP — generated by `scripts/lib/headers.mjs` into `firebase.json` **and** `_site/_headers` (Netlify/Cloudflare). Third-party hosts are added *only* when the feature needing them is enabled; image hosts are discovered from the built pages.
- No inline script/style anywhere; `npm run check` **fails the build** if one appears, or on broken links/anchors, missing alt/title/description/canonical, invalid feeds/JSON-LD, or a weakened CSP.
- DOM built with `textContent`; URLs from the search index/localStorage must be same-origin paths; e-mail obfuscated; `security.txt` auto-renewed each build.
- CI (`.github/workflows/ci.yml`): secret scan, tests, build, quality gate, `npm audit`, deploy to Firebase on `main`. Dependabot included.
- Optional: `npm run images:localize` downloads Unsplash images into the repo → no third-party requests, CSP drops the host.

## Layout
```
site.config.json     all settings           config/        Eleventy filters, collections, markdown
src/articles/        your posts             src/_includes/ layouts + components
src/pages/           static pages           src/assets/    css, js (ES modules), fonts
scripts/             build, headers, checks tests/         node:test suite (30 tests)
```
Fonts: Tiro Bangla (SIL OFL, in `src/assets/fonts/`). Originally based on the Newsprint theme; licence unchanged (see `LICENSE`).
